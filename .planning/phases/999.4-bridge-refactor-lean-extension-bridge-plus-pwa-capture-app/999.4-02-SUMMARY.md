# Phase 999.4 Plan 02: Extract bridge-core.ts + renderer.ts Summary

Extracted the token-auth route handlers into bridge-core.ts, HTML/SVG render functions into renderer.ts, deleted the hand-rolled PNG encoder, and reduced server.ts to a 166-line lean dispatcher.

## What Was Built

**src/bridge/renderer.ts** — four render functions extracted verbatim from server.ts (renderMobilePage, renderPwaAppPage, renderAppServiceWorker, renderAppIconSvg). No PNG encoder copied. No imports needed beyond template literals.

**src/bridge/bridge-core.ts** — factory function `createBridgeCoreHandler(options)` returning an async request handler. Handles all token-auth routes: /version, /health, /job/:id, /wiki/topics, /search-backend/*, /session/new-research, /session/new-wiki-ingest, /session/new-mobile-wiki-ingest, /session/append-context. Also contains captureMobilePage and all wiki ingest helpers. activeJobs Map is in the factory closure.

**src/bridge/server.ts** — 166 lines. Dispatcher pattern: /app/** and /mobile routed to handleAppRequest stub (503); everything else to bridgeCore. BridgeServerOptions aliased to BridgeCoreOptions.
