## Decisions Made

- Brainstorm mode and all wiki work session commands are TUI-only — they require interactive multi-turn sessions and cannot be meaningfully exposed as one-shot PWA actions
- Voice mode is Deferred — the Python subprocess model and Web Speech API inconsistency make it a poor quick-win candidate
- `/session/append-context` remains a 501 stub — implementing true "append to running session" semantics requires a per-session IPC channel (named pipe or socket) that does not exist in the current architecture
- The spec document `docs/browser-bridge-spec.md` is spec-lagged (documents 6 endpoints; implementation has 12) but there is no behavioral divergence — implementation is correct
- SearXNG controls intentionally excluded from PWA — mobile users cannot manage Docker containers, so this is correct design, not a gap
