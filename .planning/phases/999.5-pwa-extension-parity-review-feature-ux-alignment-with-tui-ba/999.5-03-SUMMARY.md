## What Was Built

### Task 1 — API Endpoints (bb7af8f)

Five new endpoints added to `src/bridge/app-server.ts`:

### Task 2 — Renderer Updates (8dd5217)

Three targeted changes to `src/bridge/renderer.ts`:

1. **Wiki Topics in Status tab** — `renderStatus()` now renders a "Wiki Topics" grid cell using `status.topicCount ?? 0` alongside Mode, Queued Inputs, Research Sources, and Session Folder.

2. **Flashcards section in Topics tab** — Added a `.card` block with a "Load Flashcards" button and `loadFlashcards()` async function that fetches `/app/api/flashcards` and renders Q/A pairs with source file attribution.

3. **URL linkification for research seeds** — The research seeds response handler now uses `renderMarkdown(body.answer).replace(/https?:\/\/[^\s<>"{}|\\^\x60\[\]]+/g, ...)` to render clickable `<a>` tags for any URLs in the AI output.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Backtick in regex breaks TypeScript template literal**
- **Found during:** Task 2, Update 3
- **Issue:** The URL regex character class `[^\s<>"{}|\\^\`\[\]]` contains a raw backtick which TypeScript's template-literal parser treats as a closing delimiter, producing parse errors.
- **Fix:** Replaced the backtick with its hex escape `\x60` in the regex: `[^\s<>"{}|\\^\x60\[\]]`. This is semantically identical and safe inside a JS regex.
- **Files modified:** src/bridge/renderer.ts (line 1510)
- **Commit:** 8dd5217
